One fortune cookie message for a software engineer, written as a program
for [make.fun](https://make.fun/c/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a).

## The fortune

> You will fix the bug today. The bug is the code you wrote yesterday.

## How it works

`main.py` (Python 3, standard library only) validates the line against the
competition gate — UTF-8 text, 1 to 120 characters, a single line — and
writes it to `/output/entry.txt`.

```sh
python3 main.py
```
